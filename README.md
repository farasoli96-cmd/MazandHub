# MazandHub | مازندهاب

پیش‌نمایش مفهومی نرم‌افزار مالی و عملیاتی مبتنی بر دامنهٔ ۱۰ فایل اکسل این مخزن.

## دریافت و اجرای نسخهٔ فعلی

**دانلود کد کامل (به‌همراه اکسل‌ها):** [دانلود ZIP شاخهٔ نسخهٔ فعلی از GitHub](https://github.com/farasoli96-cmd/MazandHub/archive/refs/heads/main.zip). فایل ZIP را استخراج کنید. این فایل *نصب‌کنندهٔ ویندوز یا فایل اجرایی حسابداری* نیست؛ کد پیش‌نمایش رابط کاربری است.

برای اجرا روی رایانهٔ خود، [Node.js نسخهٔ ۲۰ یا بالاتر](https://nodejs.org/) لازم است. در ویندوز، Terminal/PowerShell را در پوشهٔ استخراج‌شده باز کنید و دستورهای زیر را اجرا کنید (در macOS/Linux هم از ترمینال استفاده کنید):

```bash
cd app
npm ci
npm run dev
```

آدرس نمایش‌داده‌شده در ترمینال (معمولاً `http://localhost:5173/`) را در مرورگر **همان رایانه** باز کنید. برای توقف، `Ctrl+C` بزنید. اتصال اینترنت برای `npm ci` در اجرای اول لازم است؛ پس از نصب وابستگی‌ها، پیش‌نمایش می‌تواند محلی اجرا شود. برای بررسی build: `npm run build`.

برای آزمایش نقش‌های مختلف، یکی از حساب‌های `developer`، `manager`، `accountant`، `operator`، `sales` یا `auditor` را انتخاب کنید؛ گذرواژهٔ **نمایشی** همهٔ آن‌ها `demo1234` است.

> این برنامه فعلاً فقط نمونهٔ رابط کاربری است. ورود، نقش‌ها، رکوردها و تغییر طرح آزمایشی/حرفه‌ای در سمت مرورگر شبیه‌سازی می‌شوند؛ احراز هویت، قفل فعال‌سازی، پایگاه داده، ورود اکسل و محاسبهٔ مالی واقعی وجود ندارند. از ارقام نمایشی برای تصمیم مالی استفاده نکنید.
